# Quality check

## Does it teach?

Can someone name the idea and the action after seeing the scene? Does the character perform the explanatory action? Is the metaphor causally and spatially coherent? Can the final behaviour be practised?

## Does it read?

View every scene. Check labels, quantities, thresholds, arrow direction and outcomes. Count tally marks rather than trusting the printed number. Check connected levels and before/after states. These details can contradict an otherwise beautiful drawing.

Is the background white? Are the labels short? Is there quiet space? Do the colours keep their roles? Is the recurring character consistent enough? Is this an original scene rather than a copied example?

## Does it work?

For an interactive deck, verify all scenes and images, keyboard navigation, last-scene boundary, pop-out dismissal, notes, timing, a small-screen layout and guide links. Check the published result if requested. A generated prompt is not a generated image; a prepared publish folder is not a live website.

## Is it shareable?

Keep the source prompts and editable files. Preserve selected originals and earlier revisions. Confirm that uploaded files contain only agreed material. Include upstream credit and the MIT licence in redistributed skill packages.
