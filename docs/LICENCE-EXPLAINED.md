# MIT, in plain English

MIT stands for **Massachusetts Institute of Technology**. It is the name of a widely used open-source licence, not a Michigan university or a membership programme.

The licence gives permission to use the licensed software and documentation, copy it, change it, share it and sell it. You can use it in a business. It does not require you to make your own changes public, although Mark has chosen to publish this adaptation.

The key condition is to retain the original copyright notice and permission notice in copies or substantial portions of the licensed material. Keeping the supplied LICENSE file with the skill package is the straightforward way to do that.

It also says the material is supplied “as is”, without a warranty, and limits the authors' liability. It is not a promise that every image, instruction or result will be correct.
